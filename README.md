# Agent Eval Platform

Evaluation platform for AI agents on Vertex AI Agent Platform: eval datasets versioned here,
one eval engine (agents-cli → Vertex Gen AI Eval Service) across local / CI / on-demand surfaces,
results in GCS, thin Runner + UI.

**Building this? Start at [`docs/handoff-brief.md`](docs/handoff-brief.md)** — read order, verified
constraints, phases, and shared-machine rules are all there. The specs in `docs/` were validated
live against project `repp-501700` on 2026-08-15/16.
